# FarmBridge AI - machine learning

Two scikit-learn `RandomForestRegressor` models (inside a `Pipeline` with one-hot encoding):

| Model  | Target                              | Inputs |
|--------|-------------------------------------|--------|
| demand | `units_next_30d` (kg in next 30 days) | crop, region, month, avg weekly units (prev 4 weeks), current price/kg, supply index |
| price  | `selling_price_per_kg` (Rs/kg)      | crop, region, month, grade A/B/C, supply index, avg market price (prev 30 days) |

## IMPORTANT: the data is synthetic
`datasets/*.csv` are generated by `common.py` from seasonal/price formulas plus noise. They make the pipeline
runnable end to end. High R^2 on them means "the model learned my formulas" - **not** "it predicts real
Indian market prices". Every API response says `data_source: synthetic_demo`. To use real data, replace the CSVs
(same columns) and retrain.

## Train (run from `backend/`)
```bash
python ml_engine/generate_dataset.py     # optional: regenerate the demo CSVs
python ml_engine/train_demand_model.py
python ml_engine/train_price_model.py
```
Each script: cleans data -> 80/20 train/test split -> fits on train only -> reports MAE, RMSE, R^2 (+ a
"predict the mean" baseline and 5-fold CV) on the held-out test set -> saves `saved_models/<name>_model.joblib`
and `<name>_meta.json` (metrics, categories, training ranges). Metrics shown in the app are read from that file;
nothing is hardcoded. Retrain after upgrading scikit-learn (joblib files are version specific; they are git-ignored).

## Safe-prediction rules
* Unsupported crop -> HTTP 422 (never silently mapped to something else).
* Unseen region / input outside the training range -> prediction returned with `warnings` and `reliability: "low"`.
* New product with no sales -> typical value for that crop+month is used and flagged.
* Only products sold per kg or quintal are supported (models work in kg).
* `range` = spread across the forest's trees (10th-90th percentile), not a statistical guarantee.
* Price recommendations are stored separately and never change `Product.price` automatically.
